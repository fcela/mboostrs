# `mboostrs` Status Against the Knowledge Discovery Scorecard

This page consolidates the measured status of `mboostrs` under `mboostrs-scorecard/2.1` ([scorecard.md](scorecard.md)). Primary comparative grades come from the six-library automated held-out comparison ([held-out comparison](../book/benchmarks/heldout_competition.ipynb), [record](../book/appendix/records/heldout_fit.md)), complemented by the deterministic supplementary v2.1 benchmark protocol ([supplementary record](../benchmarks/scorecard_v21/results.json)) covering open-structure Track A (`D1a`), thin-overlap causal support (`D2`), digest/report faithfulness (`D3`), doubly-robust orthogonal CATE calibration (`D4`), 5M-row scaling and shift-warning recall (`D6`), programmatic zero-assist sessions (`D8`), and SHA-256 data/schema/environment lock verification (`D10`). No cross-study composite score is computed.

3. **Multi-library Track A open-structure comparison (D1a → 5/5):** Run competitor workflows alongside `mboostrs` under identical prescribed rough specifications.
