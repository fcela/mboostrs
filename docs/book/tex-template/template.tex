% MyST renders each part heading as \section and each notebook's own
% title as \subsection; no \chapter command is ever emitted (see
% render_mermaid.py / the toc structure in myst.yml, which nests files
% two levels below the book root). The book class's stock "headings"
% page style only refreshes the running head from \chaptermark, and
% \tableofcontents seeds that mark to \MakeUppercase{\contentsname}
% ("CONTENTS") via an explicit \markboth call before \mainmatter even
% starts. With no \chapter in the document, that mark is never
% overwritten, so every page prints "CONTENTS". Rewire the header with
% fancyhdr and make \sectionmark/\subsectionmark (silent no-ops in the
% stock class) update it, so the header tracks the current part and,
% within it, the current chapter's own title.
\pagestyle{fancy}
\fancyhf{}
\fancyhead[L]{\slshape\rightmark}
\fancyhead[R]{\thepage}
