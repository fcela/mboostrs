# All-named-reference audit

Instrument `interaction-capacity/reference-audit/1`, a posthoc reporting
extension to the immutable primary protocol. The primary protocol predeclared
the best of four tree competitors, treating Ridge as the separate scorecard
reference. The benchmark guide's strongest-method comparison also requires
considering Ridge when it wins, particularly on a null response.

Keep the original best-tree summaries and scorecards unchanged. Additionally,
for every phase/process/track choose the retrospective complete reference
among CatBoost, LightGBM, XGBoost, HistGradientBoosting and Ridge by mean outer
MSE across all eight draws. Report the same per-draw percent gap and paired
SE; winner-selection uncertainty remains excluded. Include all methods and
failures. File any point gap>1%, even if the best-tree criterion passes or the
gap is within two SE. This audit changes reporting eligibility, not any fitted
model, tuning choice or D11 grading rule. It reuses the existing outcomes and
is not a fresh independent experiment. No analytical rule is selected from
its outcome.
