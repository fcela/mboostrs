# count_incumbent_guard

This directory holds the protocol, decision documents and summary tables for
the #679 study. The raw per-seed records (`*.jsonl.xz`) and their
`*.metadata.json` files are not in the repository. They are kept in
`.remember/count_incumbent_guard_records/docs/book/benchmarks/count_incumbent_guard/`
(an untracked maintainer directory). The same files are in the repository history at
commit e9c670d7 (the merge of #721); `git checkout e9c670d7 -- docs/book/benchmarks/count_incumbent_guard`
restores them. They are regenerated by the recorders in
`benches/`: `study_interaction_incumbent.py`, `study_interaction_incumbent_v2.py`,
`study_interaction_incumbent_v3.py` and `study_interaction_production.py`.
Each recorder takes the phase and seed range given in `PROTOCOL.md` and
`PRODUCTION_DECISION.md`. The `*_SUMMARY.json` files and `CONFIRMATION_RESULT.md`
hold the aggregated results that the text cites; no test or page reads the raw records.
